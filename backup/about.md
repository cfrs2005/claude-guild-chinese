# 关于 Claude Code 周刊

## 🎯 项目简介

**Claude Code 周刊** 是最全面的 Claude Code 中文学习指南，专注于深挖未公开功能，分享实战经验，帮助开发者提升开发效率 60-80%。

### 📋 项目特色

- **实战导向**: 基于真实开发场景的教程和案例分析
- **深度解析**: 不仅教怎么用，还解释原理和最佳实践
- **中文本土化**: 针对中文开发者的使用习惯和痛点
- **持续更新**: 追踪官方最新动态和社区发展

## 📚 内容组织

### 📰 技术周刊
追踪 Claude Code 官方最新特性、模型升级、社区动态：
- **模型更新**: Sonnet 4.5 等新版本评测
- **功能发布**: 新功能深度解析和使用指南
- **社区观察**: 优秀项目点评和生态趋势分析

### 📖 官方摘录
Anthropic 官方文章的中文化解读：
- **及时翻译**: 官方公告的中文版本
- **深度解读**: 结合实际使用场景的分析
- **补充说明**: 针对中文用户的额外提示

### 🎓 实战教程
系统化的学习路径（按时间顺序）：
1. **第1章**: 快速上手 - 核心概念、基础操作
2. **第2章**: 命令系统 - 斜杠命令、钩子、MCP
3. **第3章**: 开发工作流 - 项目协同、最佳实践
4. **第4章**: 智能任务 - Meta-Todo、任务编排
5. **第5章**: 协同架构 - REPL验证、多工具协同
6. **第6章**: 命令参考 - 速查手册、故障排除

## 👥 目标用户

### 适合人群
- **前端/后端开发者**: 希望通过 AI 提升开发效率
- **技术团队负责人**: 寻求团队协作和标准化方案
- **AI 工具爱好者**: 关注最新的 AI 编程技术
- **中文开发者**: 需要中文技术文档和社区支持

### 使用前提
- 熟悉命令行操作
- 有基本的编程经验
- 了解 Git 和现代开发工具
- 能够访问 Claude Code（通过官方渠道或转发节点）
