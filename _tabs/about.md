# Claude Code 周刊

> 🚀 最全面的 Claude Code 中文学习指南 | 深挖未公开功能，提升开发效率 60-80%

## 项目概述

Claude Code 周刊是一个专注于 Claude Code 技术分享的中文项目，以周刊形式追踪官方最新特性、分享实战经验和深度技术点评。

### 主要内容

1. **基础教程系列**（第35-40期）
   - 系统化的核心功能教程
   - 适合新手快速入门
   - 静态内容，持续更新

2. **动态周刊**（第41期起）
   - 追踪最新特性、模型升级、社区动态
   - 每周五更新
   - Linus 式犀利技术点评

### 项目特色

- **技术优先**：拒绝营销话术，专注技术深度
- **实战导向**：所有内容基于实际使用经验
- **犀利点评**：独立技术判断，不盲从官方宣传
- **中文友好**：面向中文开发者的本土化内容
